# Fetch all versions available to install

This function will fetch information from Github
<https://github.com/jgm/pandoc> about available Pandoc versions
released.

## Usage

``` r
pandoc_available_releases()
```

## Value

character vector of all available release.

## See also

[`pandoc_install()`](https://cderv.github.io/pandoc/dev/reference/pandoc_install.md),
