# Open Pandoc's documentation about exit codes

Open Pandoc's documentation about exit codes

## Usage

``` r
pandoc_browse_exit_code()
```

## Value

Open the webpage at the place regarding exit code thrown by Pandoc.

## Examples

``` r
pandoc_browse_exit_code()
#> ℹ Open URL
#> https://pandoc.org/MANUAL.html#exit-codes
```
